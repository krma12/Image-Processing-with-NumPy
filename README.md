# Image Processing with NumPy

Proyecto de práctica para introducirme a la ciencia de datos con Python.

Incluye ejercicios básicos de NumPy (arrays, dimensiones, shape, operaciones),
manipulación de matrices, y análisis de una imagen usando arrays de NumPy.

## Contenido

- `test1.ipynb` — ejercicios básicos de listas y arrays de NumPy
- `project/Numpy_basico.ipynb` — introducción a NumPy
- `project/analizando_imagen.ipynb` — análisis de una imagen con NumPy
- `project/beagle.jpg` — imagen usada en el ejercicio de análisis
